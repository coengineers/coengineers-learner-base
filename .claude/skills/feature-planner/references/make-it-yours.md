# Make it yours: feature planner

What a founder may change about this skill. Their kept changes live in `skills/feature-planner.md` in their second brain, which the skill reads first. Changes cannot touch the truth, save or time rules.

## Steps
How many steps a feature is split into: three to six by default.

## The done test
Its wording. The default is start, do, see. It is always the founder's.

## Privacy
Extra people who must not see a thing, for example "not other members, and not anyone signed out".

## Hand-over
The one sentence for building. The default names the skill and the feature.

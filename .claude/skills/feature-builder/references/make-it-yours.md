# Make it yours: feature builder

What a founder may change about this skill. Their kept changes live in `skills/feature-builder.md` in their second brain, which the skill reads first. Changes cannot touch the truth, save or time rules.

## Try it
The question after each step: "Try <one thing>. Does it look right?" by default.

## Step size
Smaller steps if you want to try more often.

## Practice content
How much practice content to add so the feature is easy to try.

## Reading the change
How much you want said about a change before you say yes to it: three lines by default.

# Make it yours: feature checker

What a founder may change about this skill. Their kept changes live in `skills/feature-checker.md` in their second brain, which the skill reads first. Changes cannot touch the truth, save or time rules.

## Order
Which checks come first: the main path by default.

## Detail
How much is said about each check: one line by default.

## Extra checks
Anything you always want tried, for example a slow connection.

## Verdict
How the verdict is worded. It always says what is left and who does it.
